## What's new

- **Updates install only when you choose.** When a new version is ready, the banner on the **Home** page stays until you act on it. Closing and reopening OrthoStreamXP no longer installs the update on its own.
- **See what's new before updating.** **Update…** on the banner opens a window with the new version's release notes. Choose **Update and restart** to install it now, or **Not now** to keep the version you have.

## Good to know

- This is the last update that may install by itself when OrthoStreamXP starts, because the version you have now still works the old way. From 1.2.3 on, updates wait for you.
- As before, updates can only be installed while OrthoStreamXP is stopped, and your settings, cache and flight history stay.
